# Recycling Production Line Manager Selection System

This project demonstrates a minimal candidate evaluation system using
database design, AI prompting, and a React dashboard.

## Features
- MySQL-compatible database schema
- Faker.js-generated candidate data
- AI evaluation prompts with mock scores
- React + Vite dashboard using Mantine UI

## Setup
1. Run `npm install` inside `/RMSS`
2. Run `npm run dev`
3. Review SQL schema in `/sql`
